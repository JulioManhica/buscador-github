# Buscador de usuários do GitHub

Digite o nome de um usuário do GitHub e veja a foto, o nome e o número de repositórios dessa pessoa.

## Como usar

1. Abra o `index.html` com a extensão Live Server do VS Code.
2. Digite um nome de usuário, como `octocat`.
3. Clique em Buscar.

Se o usuário não existir, aparece uma mensagem de erro.
